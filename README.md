# LifeManager 🚀

一个使用 Python 开发的轻量级个人效率管理工具，帮助你管理日常任务、记录学习时间，并统计学习成果。

## ✨ 功能特点

- 📝 **任务管理**：添加和查看待办任务。
- ✅ **任务完成**：标记已经完成的任务。
- 💾 **数据保存**：使用 JSON 文件保存任务和学习记录。
- ⏱️ **学习记录**：记录每天的学习时间。
- 📊 **数据统计**：查看任务完成率、今日学习时间和累计学习时间。
- 🌱 **简单易用**：基于 Python 标准库，无需安装第三方依赖。

## 🛠️ 使用技术

- Python 3
- JSON
- pathlib
- datetime

## 📦 环境要求

- Python 3.9 或更高版本
- 支持运行 Python 的电脑或手机环境
